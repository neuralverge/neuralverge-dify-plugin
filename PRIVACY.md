# Privacy Policy

This plugin connects Dify to the [NeuralVerge](https://neuralverge.ai) API.

## Data collected

The plugin itself collects, stores and logs nothing. It has no storage of its own and no telemetry.

## Data sent to third parties

When a tool runs, the plugin sends the tool's input parameters (for example a search query, a page URL, a company registration number) and your NeuralVerge API key to `https://api.neuralverge.ai`, and returns the response to Dify. This is the only network destination. NeuralVerge processes these requests to produce the result and to account for usage on your plan.

The API key you enter in the plugin's credentials is stored by Dify and is sent only to `api.neuralverge.ai`, as a bearer token.
